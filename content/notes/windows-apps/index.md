## 系统与实用工具

### 软件安装与更新

🔷 **[WinGet](https://learn.microsoft.com/windows/package-manager/winget/)**

> Use WinGet to install and manage applications

{{< badge_github user="microsoft" repo="winget-cli" release=true >}}

微软开源的 Windows 命令行包管理工具，支持搜索、安装、升级和卸载软件，也可导出与导入软件清单，方便配置新电脑。

## 创作与媒体

### 截屏与录屏

🔷 **[ShareX](https://getsharex.com/)**

> Screen capture, file sharing and productivity tool

{{< badge_github user="ShareX" repo="ShareX" release=true >}}

免费开源的 Windows 截屏与录屏工具，支持滚动截图、GIF 录制、图像标注与 OCR，也可配置截图后的自动保存、复制和上传流程。
